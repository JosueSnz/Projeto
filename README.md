# Trabalho Final - Programação II

O intuito desse trabalho é analisar o consumo nacional de energia.

## Competências

- Criação de tabelas.
- Criação de gráficos ilustrativos da análise.

- Sistema de busca por data e interesse.
- Introdução a prevenção de falhas do operador.
